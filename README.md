# devin-pstack

Devin (`devin`) port of [pstack](https://github.com/cursor/plugins/tree/main/pstack) (`0.15.29`) by [Lauren Tan (poteto)](https://x.com/poteto).

See the [upstream pstack README](https://github.com/cursor/plugins/blob/main/pstack/README.md) and the [guide](./docs/guide/README.md) for usage and documentation.

## Install

Install the plugin with the Devin CLI:

```bash
devin plugins install pstack-ports/devin-pstack
```

Verify the installation:

```bash
devin plugins list
```

Then run `/pstack:setup-pstack` once to pick a reasoning budget and per-role models, and use `/pstack:poteto-mode` for anything that needs rigor.
